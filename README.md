# Dusk Shift

随日升日落，自在切换明暗。

Swift + SwiftUI 原生 macOS 菜单栏应用，支持 macOS 13 及以上。提供自动定位 / 手动城市、离线日出日落和时区查询、日出/日落独立 ±120 分钟偏移、系统外观切换、唤醒恢复和登录时启动。自动定位使用 macOS 系统服务；不调用在线地址或时区 API，不做持续高精度定位。

## 构建与运行

需要带 macOS SDK 的 Swift 6 工具链（Xcode 或 Command Line Tools），测试使用 Swift Testing。

```sh
bash scripts/test.sh
bash scripts/build-app.sh
open "dist/Dusk Shift.app"
```

请运行打包后的 `.app`，以便 macOS 正确识别自动化权限用途说明。仅在菜单栏显示太阳图标，没有 Dock 图标。默认暂停自动切换。点击菜单栏「设置…」，在「自动切换」页选择城市、设置偏移，再启用自动切换并允许控制 System Events。设置只显示控件、必要状态和异常提示，详细使用方法见本文。

请在 macOS 系统设置 → 外观中选择「浅色」或「深色」，关闭系统「自动」外观，避免两个调度器相互覆盖。暂停或退出应用会停止后续调度，保留最后的系统外观。应用退出后不能继续执行计划；可在设置中打开「登录时启动」，在下次登录 macOS 后自动运行。

构建脚本默认使用本地 ad-hoc 签名，只适合本机测试。重新构建可能需要重新授予自动化权限。正式分发需设置 `DUSK_SHIFT_SIGN_IDENTITY` 为 Developer ID 签名身份并另行公证。脚本生成当前主机架构的程序。

## 行为

- 14 个内置城市，分别保存坐标与 IANA 时区；北京、上海等共享时区的城市仍是独立选项。
- 所有显示时间均使用当前生效位置的当地时区，系统当前时区不会覆盖自动位置或手动城市。
- 日出加独立偏移后切浅色；日落加独立偏移后切深色。输入框负数提前，正数延后，范围均为 ±120 分钟。
- 两个滑块均以中点为零：日出左侧延后转亮（偏暗）、右侧提前转亮；日落左侧延后转暗（偏亮）、右侧提前转暗。拖动松开后生效；输入框按回车或失去焦点时提交，非法输入不改变计划，超范围整数限制到边界。
- 两项设置独立保存。升级保留原有日落偏移，日出默认零偏移。
- 输入有效整数时滑块与提前/延后提示立即预览，回车或失焦后提交调度。
- 界面同时显示原始日出、日落，以及已应用偏移后的「日出转亮」「日落转暗」时间，带当地日期；被边界规则跳过的切换显示「本次已跳过」，极昼极夜显示无日出/无日落。
- 极昼保持浅色，极夜保持深色。日落偏移越过调整后的下一日出时跳过该深色时段；提前超过调整后的前一日出时裁剪至该转亮边界。
- 保存城市、偏移与启用状态。启动、菜单打开、唤醒、用户会话恢复、系统时钟/时区变化时重新检查。
- 一个单次定时器：下一次外观切换或城市午夜重算；没有每秒/每分钟后台轮询。
- 每次执行先读取系统外观，只有不匹配时才设置，再读取验证。授权被拒绝后不持续弹窗，允许用户手动重试；短暂错误最多安排两次短延迟重试。
- 系统执行串行化，配置版本和执行后时间复查保证过期结果不会成为最终计划。

## 天文算法

采用 Meeus/NOAA 太阳坐标方程及标准视地平线 `−0.833°`，在所选城市的当地日期区间求太阳高度与地平线的交点。求根前补充高度极值点，避免遗漏极昼临界日的短暂昼夜区间。计算采样仅在事件触发时执行，不是后台定时轮询。算法源说明：

- https://gml.noaa.gov/grad/solcalc/calcdetails.html
- https://gml.noaa.gov/grad/solcalc/solareqns.PDF

计算不包含山体遮挡、海拔和实时气象修正，不承诺与肉眼观察分秒一致。NOAA 计算器目前已停止维护；应用运行不依赖该网站。

## 测试与实机验收

自动化测试覆盖天文参考时刻、南北半球、极昼极夜、夏令时、日期变更线、跨年、偏移边界、跨午夜、城市变更，以及通过替身外观控制器验证唤醒通知、授权失败、有限重试、并发请求和设置持久化。

当前 Command Line Tools 的 Swift Testing 框架要求 macOS 14+ 才能运行测试；应用自身部署目标仍为 macOS 13。最低系统版本的真实兼容性需在对应机器上另行验证。

以下必须在实际 macOS 登录会话中验收，单元测试不能证明这些系统行为：

1. 打开应用并启用，允许 System Events 自动化，确认系统外观和状态文字一致。
2. 选择当前处于白天/夜间的两个城市，确认全局外观分别切换，并且没有 Dock 图标。
3. 拒绝或撤销权限，确认显示错误且不反复提示；恢复权限后点击重试。
4. 设置临近日落的偏移，跨过计划时间睡眠再唤醒，确认直接恢复当前应有外观。
5. 断开网络后重复城市选择与切换；暂停、退出、重启确认行为符合上述说明。
6. 使用 Release 构建测量菜单关闭时 CPU、内存和唤醒次数；本项目不将未经测量的资源预算当作实测结果。

本版本不包含自动更新、正式签名公证及 Mac App Store 发布。

## 原生交互验证

在已授予辅助功能与屏幕录制权限的 macOS 登录会话中，可单独运行：

```sh
DUSK_SHIFT_UI_TESTS=1 bash scripts/test.sh --filter NativeInteractionTests
```

该测试使用生产 `SettingsWindowController` 打开完整设置窗口，加载 `SettingsContent` 视图；使用独立临时偏好，注入替身外观与定位服务，不改系统外观、不请求真实定位。测试通过真实鼠标事件拖动和点击控件，通过原生文本编辑器输入并派发回车，验证四个滑动方向、双向同步、失焦提交、越界/非法输入及归零。它还截取自身窗口，使用本地 Vision 识别验证两项实际显示时间。结束时恢复光标位置并清理临时偏好。

原生测试默认跳过；与普通单元测试分开运行，避免 AppKit 事件循环干扰 SwiftPM 的并发测试调度。测试宿主中控件层级的定位已在当前 macOS 验证，其他系统版本可能需要适配。它不替代菜单栏弹出层定位、真实自动化授权及实际睡眠恢复验收。

## 设置窗口与精简菜单栏（0.1.4）

菜单栏面板为 320 × 240，仅保留自动切换开关、城市与下次切换摘要、简短状态、设置和退出入口。位置模式、城市、两个偏移滑块与输入框、偏移后的切换时间和权限重试均放在独立设置窗口；悬停切换时间可查看原始日出日落。

设置窗口为单页，按需创建并复用同一个窗口。关闭设置后应用继续运行；重新打开保留选项，菜单栏和设置共享同一份状态与本地偏好。

## 语言（0.1.5）

在「设置… → 底部语言」选择跟随系统、简体中文、繁體中文或 English。默认跟随系统；不支持的系统语言回退到英语。选择立即生效并保存在本机，无需重启。窗口标题、菜单栏、城市、日期、提示和说明同步更新；语言切换不会执行新的系统外观请求或改变调度计划。

翻译资源打包在应用内部，运行不依赖源代码目录。macOS 自身授权弹窗以及系统提供的错误详情使用系统选择的语言。

## 登录时启动（0.1.6）

设置中提供「登录时启动」开关。使用 macOS 13+ 的 `SMAppService.mainApp` 注册主应用，不需要额外后台助手、LaunchAgent 文件或轮询。它在用户登录后启动菜单栏应用，保留原有城市、偏移、语言和自动切换开关；关闭此项不会退出当前应用。

状态直接来自系统，不另存自启动布尔值。需要系统批准时显示明确提示，提供「打开登录项设置…」入口；待批准状态下开关保持打开，可关闭以取消注册。打开设置或返回应用时重新读取系统状态。操作失败会显示错误并回读实际状态，不把失败显示为成功。

普通测试使用替身验证注册/取消、等待批准、错误回读、语言更新及系统设置返回后的刷新，且不改变外观调度。真实注册与取消可在已授权辅助功能的会话中运行以下脚本（临时切换一次，结束恢复原开关）：

```sh
CLANG_MODULE_CACHE_PATH="$PWD/.build/clang-cache" swift scripts/verify-login-item.swift --capture /private/tmp/dusk-shift-login.png
```

实际注销并重新登录后，应确认菜单栏图标自动出现，并恢复之前的自动切换开关。自动化注册测试不代表这个登录流程已经验收。

## 自动定位 / 手动城市（0.1.7）

设置 → 位置模式，选择「自动定位」或「手动城市」。默认保留手动模式，不自动申请定位权限。启用自动定位后，首次需在 macOS 授权；设置显示当前位置坐标、当地 IANA 时区、定位进度或失败原因，也提供「更新位置」。不使用在线反向地理编码，因此不会显示在线查询的城市名称。

手动城市始终单独保存；自动模式下仍可选择「备用手动城市」。授权拒绝、系统定位关闭、定位不可用、30 秒请求超时、时区缺失或边界重叠无法唯一确定时，立即使用手动城市重新计算。新位置成功后自动恢复自动模式；切回手动模式会取消请求、停止位置变化监测和网络事件监听，忽略迟到回调。坐标仅保存在内存，应用重启先用手动城市，重新定位后更新，不把旅行位置覆盖到手动城市偏好。

使用 `CLLocationManager.requestLocation()` 请求一次公里级定位；设备支持时订阅系统显著位置变化。网络变化、唤醒、用户会话恢复、系统时区变化和应用重新激活也会请求定位。网络事件最多每分钟触发一次请求，正在请求时合并，超时是单次定时器；没有后台定时轮询，也不调用持续定位 `startUpdatingLocation()`。不支持显著位置变化的设备依靠其他事件或手动刷新。真实通知频率由系统决定，不承诺移动后瞬时更新。

天文计算和坐标到时区的查询全部离线，时区不依赖 Mac 当前系统时区。macOS 定位服务自身可能需要 Wi-Fi 或网络，断网取得位置的能力取决于系统；获取失败后仍可用手动城市完全离线运行。Dusk Shift 不上传坐标，未实现网络地址查询或云端存储。

时区查询采用随源码打包的 ZoneDetect C 解析器（BSD-3-Clause）及约 4.7 MB 的 `timezone21.bin`，通过内存映射读取，不需要构建时下载依赖。坐标量化约 20 米；定位样本允许最大 20 km 的不确定范围，不能保证位于边界附近时的时区精度。超过 5 分钟、超过 20 km 误差、非法坐标或明显未来的定位样本会丢弃。内置时区边界数据版本为 2024a，不自动更新；时区偏移和夏令时规则由 macOS Foundation 提供。

包含 [timezone-boundary-builder](https://github.com/evansiroky/timezone-boundary-builder) 的信息，以 Open Database License 1.0 提供；数据库来自 [SwiftTimeZoneLookup 固定版本](https://github.com/patrick-zippenfenig/SwiftTimeZoneLookup/tree/7227bdc00daf0b833a8215c05d4aca05b7c0a484)，未作修改。[ZoneDetect](https://github.com/BertoldVdb/ZoneDetect/tree/81ede727f8771eda507150a95237cc8c518666d6) 的代码同样固定版本，完整许可和数据来源随 `.app` 中的 `DuskShift_DuskShiftCore.bundle` 分发，源码见 `Sources/DuskShiftCore/Resources/*-LICENSE.txt` 和 `TimezoneData-NOTICE.txt`。数据库 SHA-256：`678ab5e795975ff3f6226d3103833d984d83861b45ac7a472da9bf97de5d5e79`。

验收时先保留一个手动城市，再选择自动定位并授权，核对当前位置坐标、当地时区和计划；在系统中撤销权限后回到应用，应显示原因并回退手动城市。恢复权限并更新位置后应恢复自动计划。真实跨时区旅行、授权拒绝/恢复和长期功耗不能由替身测试代替。

## 精简设置与渐变偏移（0.1.8）

设置移除「使用说明」页、语言/登录启动的重复说明，以及偏移控件下的常驻文字提示。语言与许可入口固定在底部；自动切换状态、定位失败、权限问题、特殊天文日期等必要提示仍按情况显示。时间区域突出「日出转亮 / 日落转暗」，悬停可查看原始日出/日落。

两组偏移使用原生 NSSlider 自绘渐变轨道和圆点：日出左深右浅，日落左浅右深。中心标记表示零偏移，中心到圆点的选中区间随拖动加深或变浅，圆点内色也随位置变化。两端保留太阳/月亮图标与简短方向标签，数值输入、提前/延后摘要和归零均保留。

行为仍为左拖延后、右拖提前，日出左暗右亮、日落左亮右暗；±120 分钟范围和负数提前、正数延后的输入语义保持。鼠标松开提交，输入回车/失焦提交。方向键每次 1 分钟，Option + 方向键每次 10 分钟，VoiceOver 增减动作每次 1 分钟。渲染仅随控件状态变化，无动画定时器。

## 灰色轨道与局部渐变（0.1.9）

两条偏移滑块复用同一个原生组件，每条都是一根连续的圆角轨道，只配置日出/日落的明暗方向。零偏移时轨道和圆点均为深灰色。拖动后，仅中心到圆点的区间显示从灰色向明暗色过渡的渐变；圆点以外和未选中的另一侧保持灰色。取消轨道中间的分界线，避免两段拼接感，零位仍通过下方的 0 标识。

圆点随偏移程度渐变为原有的深蓝或浅金色；回到零位或归零时清除颜色。鼠标、键盘、辅助功能、输入同步和提交时机保持不变。

## 柔和底轨与双向显色（0.1.10）

未选中底轨随界面外观调整：浅色界面用柔和浅灰，深色界面用略亮于卡片背景的灰色。两条滑块同步使用新配色；日出左移与日落右移显示可辨识的蓝色渐变，另外两个方向显示暖金色渐变。小幅偏移采用较快的显色曲线，减少被圆点遮挡后看不出选中颜色的问题；零位仍为全灰，未选中的区域保持原底轨颜色。

## 小偏移显色与设置局部更新（0.1.11）

未选中轨道沿用柔和浅灰（深色界面用略亮于背景的灰色）。偏暗方向改为低饱和蓝灰色，深色窗口使用更亮的蓝灰色；偏亮方向保持暖金色。非零小偏移即有明显圆点颜色，选区从灰色快速过渡到选中色，5 / 10 / 15 分钟偏移均覆盖渲染验证。两条滑块仍复用同一个组件。

设置按区域独立订阅显示状态。普通偏移编辑仅通知当前偏移控件和切换时间；后台外观校验不会禁用整个表单或短暂替换状态文字，另一条滑块、位置、登录启动和语言区域保持。更新合并到主运行循环，兼容 AppKit 跟踪/嵌套事件循环，输入绑定始终读取真实设置值。输入焦点、滚动位置及另一控件的原生实例均有原生回归验证。

真正的系统主题变化、权限错误、位置/语言变化及特殊日期提示仍会更新对应区域；系统主题实际改变时，面板照常跟随深浅外观。偏移编辑保留现有自动化错误，不反复收起/展开错误行，也不会隐式重试已拒绝的授权；手动检查仍可重试。
